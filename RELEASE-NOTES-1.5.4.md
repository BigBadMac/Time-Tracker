# Time Tracker 1.5.4 - release notes (FULL DRAFT, for Brent to trim)

## Sync settings are easier to find
- Account now has a clear Sync Settings button (it replaces the "Sync this board" row).
- Right under it, Account shows how sync is set: "Sync currently set to Smart" (or whichever you picked). When sync is off it says so plainly, with OFF in red.
- The lightest How often choice is now called "On app open": it syncs when you open or come back to the app, or tap Sync now.
- The manual's sync guide shows the new button.
