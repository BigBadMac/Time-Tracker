# Time Tracker 1.5.1 - release notes (FULL DRAFT, for Brent to trim)

## Fix
- Sign-in codes can now be six or eight digits. Before, the app only took six, so an eight-digit code couldn't be entered.
- Type the code and it signs in by itself: straight away once the whole code is in, or after a moment for a six-digit code. Pasting the code, or tapping the suggestion from Mail, signs in at once. Sign in still works too.
- The app remembers which length worked, and shows the right number of boxes next time.

(Everything in 1.5 - syncing your board between your own devices - is unchanged.)
